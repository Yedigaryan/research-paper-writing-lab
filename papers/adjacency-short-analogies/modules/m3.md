# Module m3: Connectivity from the adjacency matrix

Register: study-note. Claim ids in this report are `C..` (existing, in
`evidence/evidence.json`) and `m3-..` (this module's fragment,
`evidence/modules/m3.json`). Textbook page numbers are printed pages (PDF page
minus one). Kinds of statement are named in the text: established fact (cited),
derived result (proved here), computation (script), interpretation, estimate.

## 1. Purpose

Answers board question 2, "how to know if the graph is connected or not", from
A alone, and gives the proof that the answer is correct. It establishes:

1. Definition of connected (textbook Definition 2.1.1, printed p. 48) and of
   components (printed p. 49, Remark 2.1.1), with the reflexive, symmetric,
   transitive proof the book leaves out.
2. The test: G is connected if and only if every off-diagonal entry of
   B = A + A^2 + ... + A^(N-1) is positive; equivalently (I + A)^(N-1) has no
   zero entry.
3. A connected and a disconnected three-vertex example with every matrix
   written out (computed, Section 5).
4. Breadth-first search (BFS) as an alternative, in one paragraph, now sourced.

## 2. Prerequisites

Shared terms, one meaning each (as in the brief): G = (V, E) a finite simple
undirected graph, V = {n_1, ..., n_N} with N >= 1, A the N by N adjacency
matrix (A_ij = 1 if n_i and n_j are adjacent, 0 otherwise), e_{ij} the edge
joining n_i and n_j.

- Walk, length of a walk: owned by m2 (textbook Definition 1.2.10, printed
  p. 21). A walk of length k is a vertex sequence u_0, u_1, ..., u_k with
  u_{t-1} adjacent to u_t. Repeats are allowed. Length 0 (one vertex) is
  allowed; this is the paper's convention, and the textbook's usage agrees
  (distance property 1, p. 23; reflexivity of alpha, p. 49; Grinberg
  Definition 2.9.1(a) has k >= 0; see `graph-sources.md`).
- Path: a walk with no repeated vertex (course convention; textbook
  Definition 1.2.13 "simple path", p. 22). The textbook's own word "path"
  (Definition 1.2.12) is the English trail. Owned by m2.
- Theorem W (walk counting, owned by m1): (A^k)_ij is the number of walks of
  length exactly k from n_i to n_j, for k >= 1 (and k = 0 with A^0 = I).
  Stated in the University of Galway notes Theorem 1.1.3, printed p. 4 (C31),
  Gotti Proposition 2 (C34), Bai Theorem 1 (C38).
- Lemma P (owned by m2): if there is a walk of length k from u to v, there is
  a path from u to v of length at most k (Grinberg Corollary 2.9.7, p. 39,
  C48; the textbook's Lemma 1.2.1, p. 23, covers u different from v, C25);
  and a path in a graph with N vertices has length at most N - 1, because a
  path of length k has k + 1 distinct vertices (Grinberg p. 40, C49).
- Matrix product: (XY)_ij is the sum over r of X_ir Y_rj. Powers A^k are
  repeated products; A^0 = I, the identity (1 on the diagonal, 0 elsewhere).
  Matrix entries of A^k are non-negative integers because A has entries 0 or 1.

If m1 or m2 change the statement of Theorem W or Lemma P, Section 3 changes
with it; Section 8 lists exactly what is used.

## 3. Explanation from first principles

### 3.1 Connected and components

Definition (textbook Definition 2.1.1, printed p. 48; viewed as image; C27):
a graph G is connected if for any two vertices u and v there is a (u, v)-path.
The board says the same (C7: "for any n_i, n_j there exists a path between
nodes"). Two readings of the word "path" are in play:

- The textbook's Definition 2.1.1 uses the book's "path" (a trail).
- The course convention (and this paper) uses the vertex-distinct path.

Lemma M3.6 (derived, m3-9): the two readings define the same notion of
connected. Proof. Let u and v be vertices. If u = v, the length-0 walk is both
a trail and a path. Let u differ from v.
(i) A vertex-distinct path u_0, ..., u_k (k >= 1) is a trail. Suppose edges
e_s = u_{s-1}u_s and e_t = u_{t-1}u_t coincide for s < t. The indices
s-1, s, t-1, t satisfy s-1 < s <= t-1 < t, so s-1 differs from both t-1 and
t, and the vertex u_{s-1} is distinct from both ends u_{t-1}, u_t of e_t. But
u_{s-1} is an end of e_s = e_t, a contradiction. (ii) A trail is a walk, so by
Lemma P it contains a path with the same ends. So a (u, v)-trail exists if and
only if a (u, v)-path exists. QED.

Lemma M3.4 (derived, m3-8): the relation alpha, "u alpha v if a (u, v)-path
exists", is an equivalence relation. The textbook notes this on printed p. 49
(C28) without proof ("notes", not "proves"). Proof.
Reflexive: the length-0 walk from u to u is a path. Symmetric: reversing a walk
gives a walk, and reversing a path gives a path. Transitive: if W_1 is a walk
from u to v and W_2 from v to w, writing W_1 then W_2 (dropping the repeated v)
is a walk from u to w; by Lemma P it contains a path from u to w. QED.

Components (printed p. 49): the classes of alpha, and the subgraphs induced on
them, are the connectivity components. Two vertices are in the same component
exactly when a path joins them.

Corollary M3.5 (textbook Remark 2.1.1, p. 49, C29; derived here from M3.4):
G is connected if and only if it has exactly one component. Proof. G is
connected iff every pair of vertices is related by alpha iff there is one
class (N >= 1 so at least one class exists). QED.

Textbook example and non-example (m3-14): the three graphs under Fig. 2.1.1
(printed p. 48) are connected; the graph of Fig. 2.1.2 (printed p. 49) is not,
and has four components.

### 3.2 The reading of A that answers the question

Lemma M3.1 (derived, m3-5; reachability). For i different from j, there is a
path from n_i to n_j if and only if (A^k)_ij > 0 for some k with
1 <= k <= N - 1.

Proof. (=>) Let a path have length k. Distinct vertices give k >= 1. It has
k + 1 distinct vertices among N, so k + 1 <= N, that is k <= N - 1. A path is
a walk, so by Theorem W the entry (A^k)_ij counts at least this walk and is at
least 1. (<=) A positive entry (A^k)_ij means, by Theorem W, at least one walk
of length k from n_i to n_j. By Lemma P there is a path of length at most k, and
k <= N - 1. QED.

Why N - 1 and why the lemma P step is needed: the positive entry is a walk
count, and a walk may go back and forth. The cut-down to a path is the step that
Paramadevan and Sotheeswaran's proof of the same test passes over (C43) and
that Bai's sketch states loosely (C41). The step costs nothing in length: the
path is not longer than the walk.

Theorem M3.2 (sum test; derived, m3-6). Let B = A + A^2 + ... + A^(N-1). G is
connected if and only if B_ij > 0 for all i different from j.

Proof. Each A^k has non-negative entries, so B_ij = the sum of (A^k)_ij over
k = 1, ..., N-1 is positive exactly when at least one term is positive. By
Lemma M3.1 that holds exactly when a path joins n_i and n_j. By the definition
of connected (and reflexivity for i = j), G is connected exactly when every pair
with i different from j is joined by a path. For N = 1 the sum is empty, there
are no off-diagonal entries, and G is connected; the statement holds without
content. QED. The statement is Paramadevan and Sotheeswaran Theorem 2, p. 17
(C42); the proof is the paper's own.

Theorem M3.3 (power test; derived, m3-7). G is connected if and only if every
entry of (I + A)^(N-1) is positive.

Proof. I commutes with A, so the binomial theorem applies:
(I + A)^(N-1) = sum over k = 0, ..., N-1 of C(N-1, k) A^k, where C(N-1, k) is
the binomial coefficient, a positive integer for 0 <= k <= N-1. Take i
different from j. Then I_ij = 0 (the k = 0 term), so the (i, j) entry is the
sum over k = 1, ..., N-1 of C(N-1, k)(A^k)_ij. All terms are non-negative and
all coefficients are at least 1, so the entry is positive exactly when some
(A^k)_ij, 1 <= k <= N-1, is positive, that is exactly when B_ij > 0. On the
diagonal the k = 0 term contributes C(N-1, 0) I_ii = 1, so each diagonal entry
is at least 1 whatever the graph. Hence "no zero entry" means "all off-diagonal
B_ij positive", and Theorem M3.2 finishes. QED. The statement is Gotti
Proposition 3, p. 2 (C36) and Bai Theorem 2, p. 1 (C40); Gotti's proof uses the
same binomial identity (C37). The equivalence of the two forms (C52) is
shown here, not taken from a source.

So the answer to board question 2 is: form B (or (I + A)^(N-1)), look at the
cells off the diagonal (or at all cells for the power form); connected if none
is zero.

### 3.3 What the test does not say

- The diagonal is ignored in the sum test. A connected graph can have zeros on
  the diagonal of B: N = 2, one edge, B = A = [[0,1],[1,0]] (m3-11).
- One power is not a test. On the path n_1, n_2, n_3 with N = 3, the only power
  tried would be A^(N-1) = A^2, and (A^2)_12 = 0 although n_1 n_2 is an edge.
  Reason in words: every edge of this graph joins {n_1, n_3} to {n_2}, so every
  walk from n_1 to n_2 has odd length; A^2 sees only even lengths (m3-11).
- A positive (A^k)_ij says a walk of length exactly k exists, hence a path of
  length at most k. It does not say a path of length exactly k exists.
- The entries of B and (I + A)^(N-1) are walk counts, not path counts; only
  positivity is used. (B_22 = 2 below counts the walks n_2 n_1 n_2 and
  n_2 n_3 n_2.)

### 3.4 Breadth-first search, for comparison (one paragraph for the paper)

Breadth-first search (BFS) from a start vertex s visits s, then all neighbours
of s, then all not yet visited neighbours of those, layer by layer, and stops
when a layer is empty. Lau's CS 341 Lecture 5 lists "To determine whether a
given graph is connected" among the questions BFS answers, in O(n + m) time
(m3-1, page 4), and states the lemma "There is a path from s to v if and only
if visited[v] = true at the end" (m3-2, page 8). McCauley's Lecture 4 states
that in a connected undirected graph BFS from any vertex visits every vertex,
and that BFS does not visit all nodes on a graph that is not connected
(m3-3, pp. 10 and 7). Together: run BFS from n_1; G is connected exactly when
all N vertices are visited (m3-4, an interpretation that restates the two
cited statements for the paper's definition; the paper cites the BFS lemma and
does not prove it). BFS reads A row by row and needs no matrix powers. It also
returns the component of n_1 and shortest-path distances (Lau, same lecture; not
used further). Cost, an estimate by counting (m3-13): about N^2 steps on an
adjacency matrix (one row of N entries per visited vertex); N - 2 matrix
products of about N^3 multiplications each for the matrix tests with the
definition of the product; O(n + m) on adjacency lists (Lau, page 3 and 4).
The brief excludes complexity beyond a short remark, so the paper should keep
this to one sentence.

## 6. Assumptions and their reasons

- Finite simple undirected graph, N >= 1: stated by the user (C9, qualified:
  the user's own words are not available) and consistent with the board
  matrix (symmetric, zero diagonal). N = 0 is excluded: connected with no
  vertices is a convention fight with no use here.
- Walks of length 0 allowed: needed for reflexivity of alpha and for the
  statement "for every i, j" to reduce to "for every i different from j";
  agreed by textbook usage and Grinberg (see Section 2).
- Path means no repeated vertex (brief; C8, qualified). Lemma M3.6 shows the
  textbook's trail reading gives the same notion of connected, so the answer
  does not depend on this choice for connectivity. It does for distance (the
  textbook's Definition 1.2.16 uses shortest trail); this module does not use
  distance.
- Walk counting (Theorem W) and Lemma P are used as stated by m1 and m2, with
  their own proofs. No module-level assumption beyond these is added.

## 7. Limitations, failure cases, competing explanations

- The test needs N - 1 as the top power. Stopping earlier can give a false
  "not connected": on the path n_1 ... n_4 (N = 4) the pair n_1, n_4 appears
  first at k = 3. Computed with the script's functions (ad hoc run, same
  integer code): (A^1)_14 = 0, (A^2)_14 = 0, (A^3)_14 = 1; the sum up to A^2
  has entry (1,4) equal to 0, the sum up to A^3 has 1. The exhaustive check
  covers the full test only, for N up to 6.
- Positive entries can be large for a connected graph (N = 3 triangle: 3).
  Only zero versus nonzero matters; overflow is out of scope for the paper.
- Cost (m3-13, estimate): the matrix tests are not the cheap way. With the
  definition of the product, one N by N product is N^3 multiplications; the
  sum needs N - 2 products and the power form needs N - 2 by repeated
  multiplication, about log2(N - 1) by repeated squaring. BFS is cheaper. The
  paper states the matrix test because the question asks for a test using A,
  not because it is efficient.
- Competing statements in sources: Bai writes that (I + A)^(N-1)
  "aggregates all paths" (C41); Paramadevan and Sotheeswaran read B_ij as
  "number of different paths" (C43). Under the vertex-distinct reading these
  are wrong as counts (board graph: B_22 = 2 has at most one path of length less
  than 3 from n_2 to itself, the length-0 path; Bai's R_11 = 2 against one such
  path, per `graph-sources.md`). The entries count walks; the proofs here need
  only positivity. Per the style rule, put this critique in one discussion
  item, not beside the theorem.
- Unsettled readings: the board's "path" in the definition of connected is
  taken in the course convention (C7, C8). The mark above A on the board is
  assumed to be a power k (C5, qualified); this module needs only the
  consequence that A^k is used.
- BFS source limits: Lau's slides were read only in text (Section 4 notes);
  McCauley's lemma statement is for connected graphs and the converse is a
  slide remark on an example (page 7), not a stated lemma; Lau's "path" is
  not defined on the slides read. So the BFS test in the paper is stated as a
  comparison and attributed to the sources, with m3-4 flagged as an
  interpretation. A fully quotable single statement of "connected iff BFS
  from one vertex visits all vertices" was not found in the two sources.
  Lau's lemma (path iff visited) implies it with the definition of connected;
  McCauley's lemma gives one direction and the slide remark the other.
  A textbook-grade source (for example an algorithms textbook) was not opened.
