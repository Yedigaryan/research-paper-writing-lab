## 3. Explanation from first principles

The paper's definitions come in the textbook's order, with the textbook's
numbers where it has one. Numbers below are the textbook's; "paper
Theorem 1" and "Proposition 1" are the paper's own.

**Setting (N1; textbook Definition 1.1.1, p. 9; established fact for the
book, convention for the letters).** G = (V, E) is a finite simple
undirected graph: V is a non-empty finite set of vertices, E a set of
unordered pairs of distinct vertices called edges (loops and repeated
edges are excluded). Write V = {n_1, ..., n_N} (the board's letters; the
textbook writes v_i, v_1..v_n), and e = n_i n_j for an edge. Two vertices
are adjacent (textbook Definition 1.1.4, p. 11) if they form an edge.
The adjacency matrix A is the N by N matrix with A_ij = 1 if n_i and n_j
are adjacent and A_ij = 0 otherwise (textbook, p. 11, the definition
after 1.1.6, which has no number of its own). Because the pair is
unordered and has distinct members, A_ij = A_ji and A_ii = 0 (stated on
p. 11). Claims: C1, C2, C3, C4, m1-1.

**Definition 1 (walk and length; N2; textbook Definition 1.2.10, p. 21).**
A walk of length k >= 0 from u to w is a sequence u_0, e_1, u_1, ..., e_k,
u_k of vertices and edges with u_0 = u, u_k = w and e_s = u_(s-1) u_s for
1 <= s <= k. The length is the number k of edges counted with repetition.
Remark (the trap; textbook note, p. 22): vertices and edges may repeat in
a walk. Convention of the paper: k = 0 is allowed, a single vertex (u_0)
is a walk of length 0 from u_0 to u_0. The textbook does not say this in
words; its usage agrees (distance property d(u, v) = 0 exactly when
u = v, p. 23; also the reflexivity of the relation on p. 49, not viewed
by m1, so not cited as support here). Claims: C7, C8, C15.

*Remark 1 (derived).* In a simple graph two vertices carry at most one
edge, so the edges e_s are determined by the vertices. A walk is
therefore the same thing as a sequence (v_0, ..., v_k) of vertices with
A_(v_(s-1), v_s) = 1 for each s; the paper writes walks this way (as
Grinberg's Definition 2.9.1(a), p. 36). Also, A is symmetric, so reading
a walk backwards is a walk. Claim m1-2.

**Definition 2 (path; N3; textbook Definition 1.2.13, p. 22, where it is
called a simple path).** A path is a walk whose vertices are pairwise
distinct. A path between n_i and n_j, written from n_i to n_j, is a path
(v_0, ..., v_k) with v_0 = n_i and v_k = n_j. This is the course's meaning
(user summary; claim C14 is qualified because the summary is not the
user's words). The paper says in the clause that defines it that this
is the textbook's simple path. Remark (the trap): the textbook's own word
"path" (chanaparh, Definition 1.2.12, p. 22) means a walk whose edges are
pairwise distinct, in English a trail, and the textbook uses that word in
Definition 2.1.1. Two consequences of Definition 2: a path of length 0
is one vertex, so each vertex has exactly one path to itself; reversing
a path from n_i to n_j gives a path from n_j to n_i (Remark 1), so
"between" is symmetric. Claims: C10, C11, C12, C13, m1-2.

**Definition 3 (connected; N4; textbook Definition 2.1.1, p. 48,
restated).** G is connected if for every pair n_i, n_j in V there is a
path from n_i to n_j (Definition 2). The board's wording is the same
with "path" undefined (claim C17). For i = j the length-0 path settles
the condition, so only pairs with i different from j carry content.

**Proposition 1 (derived; settles the contradiction recorded by the
research step).** For a simple graph the paper's Definition 3 and the
textbook's Definition 2.1.1, read with the textbook's path (trail), are
equivalent: for every n_i, n_j there is a path from n_i to n_j iff there
is a trail from n_i to n_j.

Proof. (a) Path implies trail. Let (v_0, ..., v_k) be a path and suppose
two of its edges are equal, e_s = e_t with s < t. Then {v_(s-1), v_s} =
{v_(t-1), v_t}, so v_(s-1) is v_(t-1) or v_t. But s-1 < t-1 < t, so
v_(s-1) is at a different position from both, and the vertices are
distinct, which is a contradiction. So the edges are pairwise distinct
and the path is a trail. (b) Trail implies path. A trail from n_i to n_j
is a walk from n_i to n_j. By N6 (a walk from n_i to n_j contains a path
from n_i to n_j; proved by m2, stated for i = j as well) there is a path
from n_i to n_j. Given (a) for one direction of the quantified statement
and (b) for the other, the two definitions of connected agree. QED.
Check: script counts 0 paths with a repeated edge among all paths of
100 random simple graphs (section 5). Claim m1-4.

Note for the author: Proposition 1 is cited, in one sentence in the
paper, where Definition 3 is stated; the proof may sit in Notes on
sources if the page budget requires, but it is a complete proof and must
not be shortened.

**Theorem 1 (walk counting; N5; the textbook has no such theorem, so it
is taken from the University of Galway notes, Theorem 1.1.3, p. 4, and
Gotti, Bai, and proved here).** For every integer k >= 0 and all i, j,
the entry (A^k)_ij equals W_k(i, j), the number of walks of length k from
n_i to n_j.

Proof, by induction on k.
Base case k = 0. A walk of length 0 is one vertex v_0 with v_0 = n_i
and v_0 = n_j; it exists, and is then unique, exactly when i = j. So
W_0(i, j) = 1 if i = j and 0 otherwise, which is the (i, j) entry of
I = A^0. (The case k = 1 also holds directly: a walk of length 1 is an
edge traversed, W_1(i, j) = A_ij.)
Induction hypothesis. For some k >= 0, (A^k)_ir = W_k(i, r) for all i, r.
Step. Fix i, j. Every walk (v_0, ..., v_(k+1)) of length k+1 from n_i to
n_j has exactly one last-but-one vertex v_k = n_r for some r in 1..N.
For fixed r, sort the walks by this r. The walk is determined by the
pair (its first k+1 vertices, which is a walk of length k from n_i to
n_r; the last vertex n_j), and the pair is allowed exactly when n_r n_j
is an edge, that is when A_rj = 1. Conversely every walk of length k
from n_i to n_r followed by n_j, when A_rj = 1, is a walk of length k+1
from n_i to n_j with last-but-one vertex n_r. So the number of walks
with last-but-one vertex n_r is W_k(i, r) if A_rj = 1 and 0 if A_rj = 0,
which is W_k(i, r) A_rj in both cases. Different r give different walks,
and every walk is counted for its own r, so
W_(k+1)(i, j) = sum over r of W_k(i, r) A_rj = sum over r of (A^k)_ir A_rj
= (A^(k+1))_ij,
by the hypothesis and the definition of the product. QED.

Why this is valid: it counts each walk exactly once, by the
partition on its last-but-one vertex; nothing in it asks the vertices
to be distinct, so it counts walks, not paths. Claims: C19, C20, C21,
m1-3.

**Worked entry (N5; the board's matrix).** The board's matrix has rows
0 1 0 / 1 0 1 / 0 1 0, edges n_1 n_2 and n_2 n_3 (the drawing's third line
is not used; see the brief). By Theorem 1 the entries of A^2 are
W_2(i, j):

A^2 = rows 1 0 1 / 0 2 0 / 1 0 1.

(A^2)_11 = 1: the single walk of length 2 from n_1 to n_1 is n_1, n_2,
n_1. It repeats n_1, so it is not a path. Hence the entry counts a walk
that is not a path, and the statement "(A^k)_ij counts paths" is wrong
for this graph. Contrast: (A^2)_13 = 1 counts n_1, n_2, n_3, a path.
(A^2)_22 = 2 counts n_2, n_1, n_2 and n_2, n_3, n_2, neither a path.
Claims: C22 (derivation now supplied), m1-5.

## 10. Optional O2 (assigned to m1; write only if the page budget allows)

For i different from j in a connected graph, the least k with
(A^k)_ij > 0 is the distance from n_i to n_j. By Theorem 1 the least
such k is the least length of a walk from n_i to n_j, and by N6 (m2) a
shortest walk is a path, since a shorter path would be a shorter walk;
trails lie between walks and paths, so the textbook's distance
(Definition 1.2.16, p. 22, shortest textbook path) is the same number.
The source is Paramadevan and Sotheeswaran Theorem 3, p. 17; claim m1-6.
