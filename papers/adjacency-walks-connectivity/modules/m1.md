# Module m1: Adjacency matrix and walk counting

Register: study-note. Claim ids in the form C<number> are in `evidence/evidence.json`; ids in the form M1-<number> are in `evidence/modules/m1.json`. Kinds of statement are named in words in the text (established fact, derived result, interpretation, and so on), not by labels.

## 1. Purpose

This module answers question (1) of the brief: what does the entry (A^k)_{ij} of a power of the adjacency matrix represent? It also fixes the adjacency matrix A and its basic properties, and it warns, with a counterexample computed by script, that the entry counts walks and not paths. Module m3 uses the theorem proved here as its main tool.

## 2. Prerequisites

Each item is defined before use. The owner module is named where it is not m1.

- Simple undirected graph G = (V, E), with N vertices (the board writes N; the textbook writes n). Established fact: the textbook's Definition 1.1.1 (printed p. 9) defines a graph as a pair of a finite nonempty vertex set V and a set E of unordered pairs of vertices, so it has no loops and no repeated edges and no direction (C8). The board writes (G, V) and "e_{ij} in V" where the textbook writes G = (V, E) and "e_{ij} in E". This is a difference of notation only; it is an interpretation recorded in the brief (C1, C7), and the board's case words are not fully legible, so C1 and C7 are qualified. This paper writes E.
- Vertex names. The board names vertices n_1, ..., n_N; the textbook writes v_1, ..., v_n. This module writes n_1, ..., n_N and uses the textbook's v_i nowhere except here. The edge between n_i and n_j is written e_{ij}; in a simple graph e_{ij} and e_{ji} are the same edge.
- Adjacent (textbook Definition 1.1.4, printed p. 11): n_i and n_j are adjacent if e_{ij} is in E (C9).
- Walk and length of a walk: owned by m2 (textbook Definition 1.2.10, printed p. 21, C23, C24). This module uses it in the following form. A walk of length k from n_i to n_j is a sequence n_i = u_0, e_1, u_1, ..., e_k, u_k = n_j of vertices and edges with e_t = u_{t-1}u_t for 1 <= t <= k. Vertices and edges may repeat, and the length is the number of edges counted as often as they occur (C24). Because G is simple, the vertex sequence u_0, u_1, ..., u_k determines the edges, so a walk may be written as its vertex sequence; the walk is then a sequence of vertices in which each two consecutive ones are adjacent. This is a derived remark (M1-6).
- Path: owned by m2. Under the course convention a path has no repeated vertex (textbook Definition 1.2.13, "simple path", C27). The textbook's own word "path" (Definition 1.2.12, C26) allows repeated vertices; this module says "path" in the course sense and "trail" for the textbook's Definition 1.2.12.
- Matrix product. For N by N matrices X and Y, (XY)_{ij} = sum over r = 1..N of X_{ir} Y_{rj}. The k-th power is A^k = A A ... A (k factors), and A^1 = A. The identity matrix I has 1 on the diagonal and 0 elsewhere; A^0 = I by convention.
- Degree d(n_i): the number of edges incident to n_i (textbook Definition 1.2.1, printed p. 16, C12). Note on order: in the textbook degree comes after the adjacency matrix, so a paper in the book's order states the matrix first and the degree property after Definition 1.2.1.

## 3. Explanation from first principles

### 3.1 The adjacency matrix and its basic properties

In plain words (story: towns joined by roads; a road joins two towns and can be driven in both directions). To record which towns have a road between them, write a table with one row and one column for each town. Put a 1 where the row town and the column town share a road, and a 0 otherwise. This table is the adjacency matrix.

Definition (adjacency matrix; the textbook gives it without a number after Definition 1.1.6, printed p. 11, C10; the board writes the same rule as A_{ij} = 1 if e_{ij} in V and 0 otherwise, C1). For G = (V, E) with V = {n_1, ..., n_N}, the adjacency matrix is the N by N matrix A = (A_{ij}) with A_{ij} = 1 if e_{ij} is in E and A_{ij} = 0 otherwise.

Remark. The definition allows only the values 0 and 1, so a repeated edge cannot be recorded; it forbids a 1 on the diagonal because a simple graph has no loop. The textbook notes both properties below (C11). The matrix depends on the numbering of the vertices; renumbering permutes rows and columns together.

Example. The board matrix with rows 0 1 0 / 1 0 1 / 0 1 0 is the adjacency matrix of the graph on n_1, n_2, n_3 with the two edges e_{12} and e_{23} (C4).

Non-example. The matrix with rows 0 1 0 / 0 0 1 / 0 0 0 is not the adjacency matrix of a simple undirected graph: it is not symmetric (Property 1 below).

Properties (derived from the definition; the textbook states the first two, C11).

1. A is symmetric: A_{ij} = A_{ji}. Reason: e_{ij} and e_{ji} name the same unordered pair.
2. The diagonal is zero: A_{ii} = 0. Reason: an edge is a pair of different vertices (no loops, Definition 1.1.1).
3. The i-th row sum is the degree: sum over j of A_{ij} = d(n_i). Proof. The sum counts the indices j with e_{ij} in E, that is, the neighbours of n_i. Every edge at n_i has the form e_{ij} with j different from i, and different edges at n_i have different other endpoints j, because a simple graph has no repeated edge. So edges at n_i and neighbours of n_i are in one-to-one correspondence, and the row sum equals the number of edges at n_i, which is d(n_i) by Definition 1.2.1. By symmetry the column sums are the same. (M1-1; this replaces the earlier qualified claim C14, whose quote was a paraphrase.)
4. The sum of all entries of A is 2|E|. Proof: add Property 3 over all i and use Euler's theorem (textbook Theorem 1.2.1, printed p. 16, C13): sum of degrees = 2|E(G)|.

### 3.3 Theorem: (A^k)_{ij} counts walks

In plain words. Start in one town and take k trips along roads, one road per trip. You may turn around and go back along the road you just used. The table with k times multiplied in it tells you, for each pair of towns, how many different k-trip journeys lead from the first town to the second. It counts journeys, not tidy routes: a journey may pass the same town twice.

Theorem 1 (walk counting; the textbook has no such theorem, so the proof below is the paper's own; the statement also appears in the University of Galway notes, Theorem 1.1.3, in Bai's notes, Theorem 1, and in Gotti's Proposition 2: C16). Let G be a finite simple undirected graph with vertices n_1, ..., n_N and adjacency matrix A. For every integer k >= 1 and all i, j in {1, ..., N}, the entry (A^k)_{ij} equals the number of walks of length k from n_i to n_j.

Proof, by induction on k (M1-2; the method and the splitting by the last-but-one vertex are those of C17).

Notation. Let W_k(i, j) denote the set of walks of length k from n_i to n_j, written as vertex sequences (u_0, ..., u_k) with u_0 = n_i, u_k = n_j and every consecutive pair adjacent (Section 2). The claim is (A^k)_{ij} = |W_k(i, j)|.

Base case k = 1. A walk of length 1 from n_i to n_j is a sequence (n_i, n_j) with n_i and n_j adjacent. There is exactly one such walk if e_{ij} is in E and none otherwise. So |W_1(i, j)| = A_{ij} = (A^1)_{ij}.

Induction hypothesis. Suppose k >= 1 and (A^k)_{ir} = |W_k(i, r)| for all i and r.

Step. Take a walk (u_0, ..., u_k, u_{k+1}) in W_{k+1}(i, j) and let n_r = u_k be its last-but-one vertex, so n_r is one of n_1, ..., n_N. Then (u_0, ..., u_k) is in W_k(i, r), and n_r is adjacent to n_j. Conversely, any walk in W_k(i, r) followed by n_j, where n_r and n_j are adjacent, is a walk in W_{k+1}(i, j). This gives, for each fixed r, a one-to-one correspondence between the walks in W_{k+1}(i, j) whose last-but-one vertex is n_r and the pairs (a walk in W_k(i, r), the edge e_{rj}), where the second part exists exactly when A_{rj} = 1. Hence the number of such walks is |W_k(i, r)| A_{rj}, which is 0 when A_{rj} = 0. Each walk has exactly one last-but-one vertex, so the sets for different r are disjoint and together cover W_{k+1}(i, j). Therefore

|W_{k+1}(i, j)| = sum over r = 1..N of |W_k(i, r)| A_{rj} = sum over r of (A^k)_{ir} A_{rj} = (A^{k+1})_{ij},

where the second equality is the induction hypothesis and the third is the definition of the matrix product. This completes the induction. QED.

Why the proof is valid. The proof uses only three facts: a walk of length k+1 is a walk of length k plus one more edge; that edge exists exactly when the matrix entry is 1; and the matrix product sums over the possible last-but-one vertex. Simplicity is used to write a walk as a vertex sequence. Nothing forbids repeating a vertex or an edge, so the count is of walks. It is also why the proof does not count paths: the product (A^k)_{ir} A_{rj} multiplies a count by 0 or 1 and never checks which vertices the first part visited.

Remark 1 (k = 0). With A^0 = I, the entry (A^0)_{ij} is 1 if i = j and 0 otherwise, which matches the walks of length 0, namely the single vertex sequence (n_i). The textbook is silent on whether k = 0 is allowed in Definition 1.2.10 (module m2 viewed printed pp. 21 to 23 and records this); the paper adopts k = 0 as a convention, following Grinberg's Definition 2.9.1(a), which has k >= 0 (claim C-m2-06). The theorem here is stated for k >= 1, and the k = 0 case is that convention (qualified).

Remark 2 (more properties, derived, M1-3).

- (A^k)_{ij} is a nonnegative integer. A is a 0-1 matrix and sums and products of nonnegative integers are nonnegative integers.
- A^k is symmetric. The transpose of a product reverses the order, so (A^k)^T = (A^T)^k = A^k. Walk meaning: reversing a walk from n_i to n_j gives a walk from n_j to n_i of the same length, a one-to-one correspondence.
- (A^2)_{ii} = d(n_i). Proof: (A^2)_{ii} = sum over r of A_{ir} A_{ri} = sum over r of A_{ir}^2 = sum over r of A_{ir} (entries are 0 or 1) = d(n_i) by Property 3. Walk meaning: the walks of length 2 from n_i to itself are (n_i, n_r, n_i), one for each neighbour n_r. The Galway notes state the same fact (C20).
- The trace of A^2 (the sum of its diagonal entries) is 2|E|, since it is the sum of the degrees (Theorem 1.2.1).

### 3.4 Walks are not paths

In plain words. The table counts every journey, including those that go to a neighbouring town and straight back. A tidy route visits each town at most once. Counting journeys gives more than counting tidy routes, and it also gives positive numbers when no tidy route exists.

Remark (the main warning, derived and computed by script, M1-5). Under the course convention a path has distinct vertices (C27, textbook Definition 1.2.13). Bai's notes say that the entry counts walks, not paths, because matrix multiplication accumulates all edge sequences including those that revisit vertices (C19). Two counterexamples in the board graph (edges e_{12}, e_{23}), both in Section 5:

1. (A^2)_{11} = 1 > 0, but there is no path from n_1 to n_1 of length 2: a sequence (n_1, x, n_1) repeats n_1. The counted walk is (n_1, n_2, n_1). In general (A^2)_{ii} = d(n_i) > 0 whenever n_i has a neighbour (C20, C21).
2. (A^3)_{12} = 2, but exactly one path joins n_1 to n_2 (the edge, length 1) and none has length 3. The two counted walks are (n_1, n_2, n_1, n_2) and (n_1, n_2, n_3, n_2).
3. (A^4) is not the zero matrix although N = 3 and a path has at most N - 1 = 2 edges (C35). So the entries of high powers cannot be counts of paths.

Paramadevan and Sotheeswaran, Theorem 1, says the entry counts "different paths" of length l (C22). This is incorrect as written: example 1 is a counterexample under any convention in which a path cannot revisit n_1. Possible reading: they use "path" for "walk"; this is a guess, not found in the source. Cite them for the statement of the connectivity test only (see m3), never for walk counting.

Where the count equals a path count. For k = 1 every walk is a path. For (A^2)_{ij} with i different from j, a walk (n_i, n_r, n_j) has distinct vertices exactly when r is different from i and j, which is automatic since n_r is adjacent to both and G has no loops. So for i different from j, (A^2)_{ij} is the number of paths of length 2 from n_i to n_j. For k = 3 and later, repeated vertices can occur even when i is different from j (example 2). This is a derived result.

- Finite simple undirected graph: the user's assignment; the board matrix is symmetric with zero diagonal (brief section 7).

## 7. Limitations, failure cases, competing explanations

- The theorem is stated for simple undirected graphs. With loops, A_{ii} would be 1 or 2 depending on convention, and the row-sum property changes; with multiple edges the entries are edge multiplicities and the theorem counts walks with edge choices. Out of scope.
- The textbook was not read in full; C15 (no walk-counting theorem in the textbook) is a result of a search and the pages viewed, so the paper should phrase it that way. Result of a search plus the pages viewed: a pdftotext search for the incidence-matrix term (կցության) gives hits on PDF pages 4, 8, 13, 39, 42, 45, 46, 53, 54, 112, 113, and the viewed page image of PDF page 8 (printed p. 7, the list of basic notations) lists A(G) as the adjacency matrix of G (հարևանության մատրից) and B(G) as the incidence matrix (կցության մատրից). So the term in the search is the incidence matrix and its hits are not adjacency-matrix pages, and printed p. 7 does mention the adjacency matrix, as a notation entry only, with no theorem. The other hit pages were not viewed. C15 stays qualified.
- Sources: all three that state the theorem are lecture notes; none was read for anything beyond the statement and the short proof.
- Competing explanation of the board mark: if the mark is a prime or quotation marks, question 1 would ask about another matrix. The user's text rules this out, but the board itself does not.
- Competing reading of Paramadevan's Theorem 1: see 3.4.
- Entries of A^k grow quickly (A^4 of the board graph already has 4); the module makes no claim about growth rates, which would need eigenvalue methods (out of scope).
