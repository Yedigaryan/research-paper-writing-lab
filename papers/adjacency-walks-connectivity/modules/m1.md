## 1. Purpose

Establishes (a) the adjacency matrix A of a simple undirected graph and its
basic properties, (b) the theorem that (A^k)_ij is the number of walks of
length k from n_i to n_j, with a full induction proof, and (c) that this
counts walks, not paths, with a counterexample. It serves research
questions 1 (what (A^k)_ij represents) and, as the base for m3, question 2.

## 2. Prerequisites

- Graph G = (V, E), V = {n_1, ..., n_N}, E the set of edges, N = |V|.
  Board writes (G, V) and e_ij in V; the textbook writes G = (V, E) and
  e = uv (Definition 1.1.1, p. 9). Notation difference only (brief, section 7).
- Simple graph: no loops, no repeated edges (Galway notes, Definition 1.1.1,
  p. 1). Undirected: an edge is an unordered pair.
- Adjacent: n_i and n_j are joined by an edge (textbook Definition 1.1.4,
  p. 11).
- Degree d(n_i): number of edges at n_i (Definition 1.2.1, p. 16).
- Walk of length k from n_i to n_j: owned by m2 (textbook Definition 1.2.10,
  p. 21). Used here as the sequence n_{i0}, e_1, n_{i1}, ..., e_k, n_{ik}
  with e_s joining n_{i(s-1)} and n_{is}; in a simple graph it is determined
  by its vertex list. Vertices and edges may repeat. Length = number of
  edges. Path (course convention, textbook "simple path", Definition 1.2.13):
  walk with no repeated vertex (m2). Trail (textbook "path", Def. 1.2.12):
  walk with no repeated edge (m2).
- Matrix product: for N by N matrices X, Y, the (i,j) entry of XY is
  sum over r = 1..N of X_ir Y_rj (row i of X against column j of Y).
  A^0 = I (identity), A^(k+1) = A^k A.

## 3. Explanation from first principles

**Definition (matrix rule, textbook p. 11, after Definition 1.1.6; no number
of its own).** A is the N by N matrix with A_ij = 1 if n_i and n_j are
adjacent and 0 otherwise. The board writes this with e_ij; the book never
writes e_ij (graph-sources.md; claim C1). Established fact (C1, C2).

Basic properties:

1. Entries are 0 or 1 (by the rule).
2. A_ii = 0: a simple graph has no loops (C2, textbook p. 11).
3. A_ij = A_ji: adjacency is symmetric because an edge is unordered (C2).
4. Row sums are degrees (derived result, section 5.1; M1-1).
5. A^k is symmetric (derived, section 5.5; M1-6).

Plain words for the report's reader: A is a table. Row i, column j holds 1
when there is a road between town i and town j, else 0. A^k answers "in how
many different trips of exactly k road-steps can I get from town i to town j,
turning back and revisiting allowed?"

Why walks and not paths: multiplying matrices adds up, over every possible
middle town, the number of ways to reach the middle town times the number of
ways to go on. Nothing in that sum records which towns were already visited,
so repeated towns are counted (claim C6, Bai Theorem 1 and following
paragraph, p. 1, interpretation supported by the proof in 5.3).

Board graph (brief, section 5; claim C29): matrix rows 0 1 0 / 1 0 1 / 0 1 0,
edges n1n2 and n2n3 only. The drawing's third line (1-3) and the arrowhead
are not encoded in the matrix; the matrix is taken as the graph (brief,
section 7). Reporting the mismatch belongs to the paper's conventions list.

## 5. Derivations and calculations

### 5.1 Row sums are degrees (M1-1, replaces unverified C4)

Statement (derived result). In a simple undirected graph, for every i,
sum over j of A_ij = d(n_i).

Proof. Fix i. By the matrix rule A_ij is 1 exactly when n_j is adjacent to
n_i and 0 otherwise, so the sum over j equals the number of j with n_j
adjacent to n_i, call it a_i. Because the graph is simple, two distinct
edges at n_i never go to the same neighbour (no multiple edges), and no edge
at n_i goes back to n_i (no loops, A_ii = 0). So the map "edge at n_i to its
other end" is a bijection from the edges at n_i to the neighbours of n_i.
Hence a_i is the number of edges at n_i, which is d(n_i) by Definition
1.2.1. QED.

Corollary. The sum of all entries of A is sum_i d(n_i) = 2|E| by Euler,
Theorem 1.2.1 (p. 16). The column sums equal the row sums by symmetry.

Failure outside the scope: with loops or multiple edges the entry may
exceed 1 or a loop may count once or twice; the statement then changes.
Not used here.

Check by script (output copied):

```
A (board)       0 1 0 / 1 0 1 / 0 1 0
row sums: [1, 2, 1]  degrees by counting edges: [1, 2, 1]
B (triangle n1n2n3 plus pendant n3n4)
row sums: [2, 2, 3, 1]
```

and over 300 random simple graphs of up to 6 vertices the row sums matched
the edge-counted degrees in every case (summary line: failures = 0).

### 5.2 (A^2)_ii is the degree; the counterexample (M1-2, replaces unverified C7)

Statement (derived result). (A^2)_ii = d(n_i).

Proof. By the product rule, (A^2)_ii = sum over r of A_ir A_ri. Since
A_ri = A_ir (symmetry), each term is A_ir^2 = A_ir, because entries are 0
or 1. So the sum is the row sum of row i, which is d(n_i) by 5.1. QED.

(Walk reading, consistent with 5.3: a walk n_i, n_r, n_i of length 2 exists
exactly for each neighbour n_r, and there are d(n_i) of them.)

Consequence. If d(n_i) >= 1 then (A^2)_ii >= 1, but no path of length 2
joins n_i to itself: a path of length 2 has 3 distinct vertices, while the
first and last are both n_i. Therefore (A^2)_ii counts walks and not paths.
Checked against the paper's length-0 convention (M1-5): the only path from
n_i to itself is the one of length 0, so the count of paths of length 2 is 0
while the entry is at least 1. The refutation does not depend on whether
length 0 is allowed.

Board graph (edges n1n2, n2n3). Output of the script:

```
A^2
   1 0 1
   0 2 0
   1 0 1
n1: (A^2)_11 = 1; walks: [(1, 2, 1)] ; paths (distinct vertices): []
n2: (A^2)_22 = 2; walks: [(2, 1, 2), (2, 3, 2)] ; paths: []
n3: (A^2)_33 = 1; walks: [(3, 2, 3)] ; paths: []
```

By hand, (A^2)_22 = A_21 A_12 + A_22 A_22 + A_23 A_32 = 1 + 0 + 1 = 2,
agreeing with the script. Diagonal [1, 2, 1] equals the degrees [1, 2, 1].
Note the closed walk n1 n2 n1 uses the edge n1n2 twice, so it is neither a
path nor a trail.

Second example with a triangle (script): B has edges n1n2, n2n3, n1n3, n3n4;
B^2 diagonal is [2, 2, 3, 1], equal to the degrees. B^3 has (1,1) = 2,
counted by the closed walks n1 n2 n3 n1 and n1 n3 n2 n1 (triangle in both
directions), which are cycles. So a positive diagonal entry of an odd power
can also come from a real cycle; the diagonal of A^2 never can.

### 5.3 Walk counting theorem (M1-3), full proof

Theorem. For a simple graph with adjacency matrix A and every integer
k >= 1, (A^k)_ij is the number of walks of length k from n_i to n_j. With
the convention in M1-5 the statement also holds for k = 0 (A^0 = I; one walk
of length 0 from n_i to n_i, none from n_i to n_j for i != j).

Proof, by induction on k.

Base case k = 1. A walk of length 1 from n_i to n_j is one edge from n_i to
n_j. By the matrix rule A_ij = 1 if there is such an edge (exactly one in a
simple graph) and 0 otherwise. So A_ij is the number of walks of length 1.

Induction hypothesis. Assume for some k >= 1 that for all i, j the entry
(A^k)_ij is the number of walks of length k from n_i to n_j.

Step. Since A^(k+1) = A^k A, the product rule gives
(A^(k+1))_ij = sum over r = 1..N of (A^k)_ir A_rj.
Count the walks of length k+1 from n_i to n_j by their last-but-one vertex
n_r. Such a walk is a walk of length k from n_i to n_r followed by one step
from n_r to n_j. The final step exists (one way) iff A_rj = 1, so A_rj is
the number of choices of that step (0 or 1). By the hypothesis there are
(A^k)_ir choices of the first part. The two parts are chosen independently
and any pair gives a walk of length k+1, with the walk recovered uniquely
from the pair (cut off its last edge). So for fixed r the number of walks is
(A^k)_ir A_rj. Different r give different walks (the last-but-one vertex
differs), and every walk has some r. Adding over r gives the sum above.
Hence (A^(k+1))_ij is the number of walks of length k+1. QED.

The case k = 0: the hypothesis for the induction may start at k = 0 with
A^0 = I, since the step above uses only the hypothesis for k. This is the
paper's convention, not the textbook's (M1-5; the book is silent, C19).

Brute-force check (script): for 300 random graphs on 1 to 6 vertices and
k = 0..4, every entry of A^k was compared with a count from explicit
enumeration of vertex sequences: 24255 entries compared, failures = 0.
(This is a test of the statement, not part of the proof.)

Other statements of the theorem: Galway Theorem 1.1.3 p. 4, Gotti
Proposition 2 p. 1, Bai Theorem 1 p. 1 (C5).

### 5.4 Walks, not paths, off the diagonal (M1-4)

Board graph A^3 from the script:

```
A^3
   0 2 0
   2 0 2
   0 2 0
length-3 walks n1 -> n2: [(1, 2, 1, 2), (1, 2, 3, 2)] paths among them: [] trails among them: []
```

So (A^3)_12 = 2. Both walks repeat a vertex (n1 and n2 in the first, n2 in the second)
and an edge; there is no path of length 3 because a path in a 3-vertex graph has at
most 3 distinct vertices, so length at most 2 (C21). Note (A^3)_12 > 0 even
though n1n2 is an edge, and (A^2)_12 = 0: parity, not connectedness
(relevant to m3: one power is not a test).

### 5.5 A^k is symmetric (M1-6)

Reversing a walk n_i ... n_j gives a walk n_j ... n_i of the same length;
this is a bijection between the two sets of walks. By the theorem
(A^k)_ij = (A^k)_ji. Alternative: A^T = A, and (A^k)^T = (A^T)^k = A^k.

## 6. Assumptions and their reasons

- Finite, simple, undirected: user's assignment, matches the symmetric
  zero-diagonal board matrix (brief, section 7).
- Mark above A is a power k: user's text (brief, section 7). Interpretation.
- Matrix is the example graph, not the drawing (brief, section 7).
- Walk of length 0 allowed (M1-5): needed so A^0 = I counts walks and so
  every vertex has a path to itself (as in Grinberg). Only the k = 0 remark
  uses it; all proofs for k >= 1 are independent of it.
- A walk in a simple graph is identified with its vertex list, valid because
  an edge is determined by its two ends.

## 7. Limitations, failure cases, competing explanations

- Multigraphs: entries may exceed 1 and the theorem counts walks with
  multiplicity; loops break the row-sum rule. One-sentence remark only.
- Directed graphs: A not symmetric, row sums are out-degrees; out of scope.
- The textbook has no walk-counting theorem (C8, qualified: text-layer
  search). The proof is therefore the paper's own; do not attribute it to the
  book.
- Paramadevan Theorem 1 says "paths" (C31), contradicting its own property 7
  (C32). The discussion item restates it as "(A^2)_11 counts paths of length
  2 from n1 to n1" and refutes it with 5.2. Keep this out of the theorem
  statement and quote verbatim with page (graph-sources.md).
- The walk count says nothing about the count of paths. Counting paths is
  not given by a matrix power.
