## 1. Purpose

This module fixes the words that m1 and m3 use. It establishes: the
textbook's Definitions 1.2.10 to 1.2.16 in the book's order; one table that
matches the course word, the textbook word and the English word; the
definition of a path between n_i and n_j under the course convention; the
lemma that every walk from u to v contains a path from u to v, with a length
bound and with u = v allowed; distance. It serves question (3) of the brief
directly, and questions (1) and (2) indirectly: m1 must say "walk, not
path", and m3 turns "there is a walk" into "there is a path".

## 3. Explanation from first principles

### 3.1 Plain words

Think of a walk as a trip along streets, where each step goes from one
corner to a neighbouring corner. You may turn around and pass a corner or a
street many times. The length is the number of steps taken. A "path" in the
course is a trip that never visits a corner twice. Everything in this module
is about how strict the trip rules are, and why a sloppy trip can always be
shortened to a strict one.

### 3.2 The definitions, in the textbook's build order

Each item gives the textbook's number, the statement, what it allows and
forbids, an example and a non-example. Examples on the textbook's graph G of
Fig. 1.2.5 (p. 21) are the book's own (M2-3); the board graph (edges
n_1n_2 and n_2n_3, drawn here as the path n_1 - n_2 - n_3) is used where the
book's graph is not needed.

**Definition 1.2.10 (walk).** A walk of length k from u_0 to u_k (a
(u_0,u_k)-walk) is a sequence u_0, e_1, u_1, ..., e_k, u_k of vertices and
edges with e_i = u_{i-1}u_i for 1 <= i <= k (C9). Remark: vertices and edges
may repeat, and the length counts each edge as often as it occurs (M2-1).
Example (book): v1,v3,v2,v4,v3,v2,v4,v3,v5 is a walk of G, length 8.
Non-example (book): v3,v1,v4,v2,v3,v5 is not, because v1v4 is not an edge
(M2-3, M2-4). Convention on length 0: the textbook definitions do not say
whether k = 0 is allowed (C19). Its distance property d(u,v) = 0 only if
u = v presupposes a trivial trail from u to u (M2-13, interpretation). This
paper adopts k >= 0 as its own convention, as Grinberg's Definition 2.9.1(a)
does (C17): the single vertex n_i is a walk of length 0. m1 and m3 need
this to read A^0 = I and to include u = v in the lemma. See section 8.

**Definition 1.2.11 (closed walk).** A walk is closed if u_0 = u_k (C10).
Remark: nothing else is required. Example: on the board graph n_2,n_1,n_2
is a closed walk of length 2. Non-example: n_1,n_2,n_3.

**Definition 1.2.12 (the book's path = English trail).** A (u_0,u_k)-walk
is a path of the book if the edges u_0u_1, ..., u_{k-1}u_k are pairwise
different (C11). Remark: vertices may repeat, edges may not. Example
(book): v1,v3,v2,v4,v3,v5 (vertex v3 occurs twice, the edges are
distinct). Non-example (book): v1,v3,v2,v4,v3,v2,v4,v3,v5, where v3v2
occurs twice (M2-3, M2-4). This paper writes "trail" for it and always
adds "(book's path, Def. 1.2.12)".

**Definition 1.2.13 (simple path = the course path = English path).** A
(u_0,u_k)-path of the book is a simple path if all its vertices are
pairwise different (C12). Remark: this is the course convention of the
brief. Because a path has no repeated vertex it has no repeated edge, so a
course path is a trail (Proposition M2.3). Example (book): v1,v3,v4,v5.
Non-example (book): v1,v3,v2,v4,v3,v5 is a trail but not a simple path.
Board graph: n_1,n_2,n_3 is a path; n_1,n_2,n_1,n_2,n_3 is a walk that is
not a trail (edge n_1n_2 twice), so not a path.

**Definition 1.2.14 (closed path or cycle of the book).** A (u_0,u_k)-path
of the book is a closed path or cycle if it is a closed walk (C13).
Remark: this is a closed trail; vertices may repeat. In a simple graph a
closed trail of positive length has at least 3 edges (Proposition M2.6,
M2-12). Example (book): v3,v2,v1,v3,v5,v4,v3. Non-example: any closed walk
that repeats an edge, for example n_2,n_1,n_2.

**Definition 1.2.15 (simple cycle).** A cycle is simple if only its first
and last vertices repeat (C14). Remark: the English cycle is the book's
simple cycle. C_n (n >= 3) is the simple cycle on n vertices, P_n the
simple path on n vertices (M2-11). Example (book): v1,v3,v4,v2,v1.
Non-example (book): v3,v2,v1,v3,v5,v4,v3, a cycle in Def. 1.2.14's sense
but not simple (M2-3, M2-4). The board graph has no cycle of positive
length: it has two edges and a cycle needs 3 (M2-12).

**Definition 1.2.16 (distance).** The distance d(u,v) is the length of a
shortest (u,v)-path of the book (a shortest trail) if one exists, and +infinity
otherwise (C15). Remark: with the course words, a shortest trail is a
shortest course path and the word "shortest path" keeps its meaning
(Proposition M2.5). Example: on the board graph d(n_1,n_3) = 2. Non-example
of a distance: 4 is the length of a walk from n_1 to n_3 but it is not the
shortest.

### 3.4 Definition of a path between n_i and n_j (question 3)

**Definition M2.1 (course convention).** A path between n_i and n_j is a
sequence u_0, u_1, ..., u_k of vertices with u_0 = n_i, u_k = n_j, each
u_{s-1}u_s an edge, and u_0, ..., u_k pairwise different. Its length is k.
This is the textbook's simple (n_i,n_j)-path, Definition 1.2.13. With the
convention of 3.2, k = 0 is allowed and n_i itself is the path between n_i
and n_i. Two vertices are joined by a path "between" them in either order
(Proposition M2.3(c)).

In plain words: a path between two corners is a trip from the first corner
to the second in which no corner is visited twice.

### 5.2 Lemma M2.2 (walk to path)

**Lemma M2.2.** Let w_0, w_1, ..., w_k (k >= 0) be a walk from u to v in a
simple graph G on N vertices. Then there is a path from u to v of length at
most k, all of whose vertices occur among w_0, ..., w_k. Every path in G has
length at most N - 1.

In plain words: any trip from one corner to another can be shortened, by
cutting out every loop, into a trip that never visits a corner twice, and
the trimmed trip is never longer.

Proof (strong induction on k). Base, k = 0: the walk is the single vertex
u = v; one vertex is a path of length 0.

Induction hypothesis: the statement holds for all walks of length less than
k, where k >= 1.

Step. If w_0, ..., w_k are pairwise different, the walk is a path of
length k, done. Otherwise there are i < j with w_i = w_j. Let
W' = w_0, ..., w_i, w_{j+1}, ..., w_k (the block w_{i+1}, ..., w_j is
deleted). W' is a walk: the consecutive pairs inside w_0..w_i and inside
w_{j+1}..w_k are edges of W, and the new neighbours are w_i and w_{j+1},
where w_i = w_j and w_j w_{j+1} is an edge. If j = k there is no w_{j+1};
then W' = w_0, ..., w_i, and it ends at w_i = w_k = v. If i = 0, W' starts
at w_0 = u and continues with w_{j+1}, which is adjacent to w_j = w_0, so
it is still a walk from u. In all cases W' goes from u to v, has length
k - (j - i) < k, and uses only vertices of W. By the hypothesis it
contains a path from u to v of length at most k - (j - i) < k. End of
proof of the first part.

Bound: a path of length k has k + 1 pairwise different vertices, and G has
N vertices, so k + 1 <= N, that is k <= N - 1 (C21).

Relation to sources. Textbook Lemma 1.2.1 (C16) is the case u != v without
the bound, and its proof is the same induction; it leaves the case j = k
implicit (M2-6). Grinberg Corollary 2.9.7 (C20) is the statement with
bound and u = v. The proof above is the module's own.

Consequence. If u != v and there is a walk of length k from u to v, there
is a path of length between 1 and min(k, N - 1). This is what m3 needs.
A single power or an exact length is not implied: a path of exactly length
k need not exist (board graph, (n_1,n_3), k = 4: 2 walks, 0 paths).

### 5.3 Proposition M2.3 (nesting and reversal)

(a) Every path is a trail. Proof: suppose a path u_0, ..., u_k has e_s = e_t
with s < t, where e_s = {u_{s-1}, u_s}. Then {u_{s-1}, u_s} = {u_{t-1},
u_t}. Since s - 1 < t - 1 and the vertices are pairwise different,
u_{s-1} != u_{t-1}, so u_{s-1} = u_t. But s - 1 < t, again two different
positions, so u_{s-1} != u_t. Contradiction.

(b) Every trail is a walk (by definition), and the inclusions are strict:
v1,v3,v2,v4,v3,v5 is a trail and not a path; n_2,n_1,n_2 is a walk and not
a trail (M2-3, M2-7).

(c) Reversal. If u_0, ..., u_k is a walk (trail, path) from a to b, then
u_k, ..., u_0 is a walk (trail, path) from b to a with the same length and
the same edges and vertices. Proof: edges are unordered pairs and the
repetition conditions do not depend on order (M2-10).

### 5.4 Proposition M2.4 (trail iff path; the word in "connected")

For u, v in V there is a (u,v)-trail if and only if there is a course
(u,v)-path. Proof. If a path exists it is a trail by M2.3(a). If a trail
exists it is a walk, so Lemma M2.2 gives a course path (this works also for
u = v, with length 0). Consequence (M2-8): textbook Definition 2.1.1 (C23),
connected, and the board's definition (C30) say the same thing whether
"path" means the book's path or the course path. m3 may use either.

### 5.5 Proposition M2.5 (distance)

Let W, T, P be the least lengths of a walk, a trail, a course path from u to
v (infinity if none). Every path is a trail and every trail is a walk, so
W <= T <= P. By Lemma M2.2 a walk of length W yields a path of length at
most W, so P <= W. Hence W = T = P (M2-9). The textbook's distance (C15) is
T, and Grinberg's remark (C22) is the same statement for W and P. Properties
of Definition 1.2.16 (book): d >= 0 and d = 0 iff u = v; symmetric;
triangle inequality; symmetry follows from M2.3(c). The brief asks only
for distance, not for its metric properties; the paper may cite the book.

### 5.6 Proposition M2.6 (short cycles)

In a simple graph a closed trail of positive length k has k >= 3. k = 1
would need an edge u_0u_1 with u_1 = u_0, a loop, not allowed. k = 2:
u, v, u uses the edge uv twice, so it is not a trail. Hence a cycle of
Def. 1.2.14 with positive length, and a simple cycle, has at least 3 edges
and 3 vertices, consistent with C_n, n >= 3 (M2-11, M2-12). A closed
trail of length 0 is excluded from "cycle" by this paper's convention:
cycles have positive length.

## 6. Assumptions and their reasons

1. Finite simple undirected graph (brief, user text, symmetric board
   matrix).
2. Course "path" = no repeated vertex = textbook simple path (user
   statement via brief). Reason: the brief fixes it.
3. A walk of length 0 is allowed; a cycle has positive length. Reason:
   Lemma M2.2 and the diagonal of A^0 = I need it, and the textbook's own
   d(u,v) = 0 iff u = v presupposes it (M2-13). The textbook definitions are
   silent (C19). This is this module's own convention, recorded for the
   paper.
4. Walks are written by vertex sequences. Reason: simple graph, the
   textbook does the same (M2-2).
5. The Fig. 1.2.5 edge list is my reading of the image (M2-4).

## 7. Limitations, failure cases, competing explanations

- Definitions are those of one Armenian textbook. Other books use
  "path" for a trail or "chain". Naming table lists only the three
  conventions in the brief.
- If length 0 is not allowed, Lemma M2.2 for u = v fails as stated
  (a closed walk would contain no path); for u != v nothing changes, since
  a walk between different vertices has positive length. Distance
  d(u,u) = 0 would then need its own sentence.
- Textbook Lemma 1.2.1 says the path can be "separated out" (առանձնացնել);
  I read this as "contains as a subsequence", which Lemma M2.2 proves; the
  book does not say this in words.
- The edge v1v5 of Fig. 1.2.5 is read from a thin line; no example in the
  book uses it, so a misreading would not change any checked statement.
- Grinberg's text is a preprint (C17 notes), used only for the
  statement; the proofs here are my own.
- Not covered: directed graphs, multigraphs (loops and parallel edges
  would change M2.3(a) and M2.6), weighted distance.
