READER SUMMARY
The note is built around a lecture whiteboard, which I cannot see, so I take the setup from the text. It answers three questions about a graph (towns joined by two-way roads) that is stored as a table of 0s and 1s called the adjacency matrix A. The first question is what the entry in row i and column j of A multiplied by itself k times means. The answer is that it is the number of walks of length k, that is, trips of k drives from town i to town j where towns and roads may repeat. It is not the number of paths (trips that never revisit a town). The proof is by induction on k, splitting each walk by its next-to-last town. The second question is how to tell from A whether every town can reach every other. The answer is that, for N towns, the graph is connected exactly when every off-diagonal entry of A + A^2 + ... + A^(N−1) is positive. Equivalently, the matrix (I + A)^(N−1) has no zero entry. The reason is that any walk can be shortened to a path by cutting out loops, and a path has at most N−1 drives. The third question is the definition of a path between two towns. The answer is a sequence of pairwise different towns, each adjacent to the next. This is the course meaning, and it differs from the textbook's word "path", which allows repeated towns but not repeated roads. The paper shows both meanings give the same connected graphs. It works a three-town example that passes the test and one that fails it, runs a computer check on all graphs with up to 6 towns, and notes that the board's drawing and matrix disagree on one edge, so the matrix was followed.
