\section{Introduction}\label{sec:intro}

\subsection{The questions and where they came from}

A graph is a set of points, called vertices, together with lines, called
edges, that join some pairs of points. A computer cannot look at a drawing,
so a graph is often given as a table of zeros and ones, the adjacency
matrix $A$, with one row and one column for each vertex. This note is
about what that table can tell us. It asks three questions.
\begin{enumerate}
\item[(Q1)] What does the entry $(A^k)_{ij}$, in row $i$ and column $j$ of
  the matrix power $A^k$, represent?
\item[(Q2)] How can we know from $A$ whether the graph is connected, that
  is, whether every vertex can be reached from every other?
\item[(Q3)] What is the definition of a path between the vertices $n_i$ and
  $n_j$?
\end{enumerate}
Questions (Q1) and (Q2) come from a lecture whiteboard that was
photographed twice from slightly different angles
\cite{whiteboard1,whiteboard2}. The board holds a rule for the entries
$A_{ij}$ of an adjacency matrix, a drawing of three vertices, a $3\times 3$
matrix with rows $0\,1\,0$, $1\,0\,1$, $0\,1\,0$, a problem statement (a
graph with $N$ nodes is given through its adjacency matrix $A$), the two
questions, and a definition: a graph is connected if for any $n_i$ and
$n_j$ there exists a path between the nodes. Question (Q3) was added by the
assignment, as it was relayed to the author of this note; the relay is a
summary and not the assignment's own words \cite{userstatements}.

The questions matter because they connect a picture to arithmetic. If
multiplying the table by itself counts routes between vertices, then a
routine calculation can answer questions that one would otherwise answer by
looking at a drawing, such as whether every vertex can be reached from
every other.

\subsection{Conventions and assumptions}\label{sec:conventions}

Where the board, the assignment as relayed, and the course textbook
(Petrosyan, Mkrtchyan, and Kamalyan, \emph{Graph Theory}, in Armenian) differ
or leave a point open, this list fixes what the note uses. Later sections
cite it by item number. The textbook is cited by printed page number; the
page of the PDF file is one higher \cite{petrosyan2015graphs}.
\begin{enumerate}
\item\label{conv:setting} \textbf{Setting.} The graph is finite, simple (no
  edge joins a vertex to itself, and no two edges have the same two ends),
  and undirected, and it has $N\ge 1$ vertices. This is how the assignment
  was relayed \cite{userstatements}; it agrees with the board matrix, which
  is symmetric and has zeros on its diagonal \cite{whiteboard1}.
\item\label{conv:names} \textbf{Names.} We write $G=(V,E)$ with $V$ the
  vertices and $E$ the edges, call the vertices $n_1,\dots,n_N$ as the board
  does, and write $n_in_j$ for the edge between $n_i$ and $n_j$. The board
  and the textbook use other letters; this is a difference of notation
  only.\footnote{The board's $V$ is the set of edges, and it writes $e_{ij}$
  for an edge. The textbook writes $v_i$ for vertices and never $e_{ij}$
  \cite[p.~9]{petrosyan2015graphs}.}
\item\label{conv:power} \textbf{The exponent.} In question (Q1) the board has
  a small mark above $A$ that could not be resolved in the photos as a
  letter $k$ or $n$ \cite{whiteboard1}. It is read as a power $k$, because
  the assignment, as relayed, asks about $A^k$ \cite{userstatements}. The
  theorem in \cref{sec:counting} holds for every $k$. If the mark were a
  pair of quotation marks around $A$, question (Q1) would ask what $A_{ij}$
  itself represents, which is the case $k=1$ of that theorem.
\item\label{conv:drawing} \textbf{The matrix defines the example.} The
  board drawing and the board matrix do not show the same graph: the drawing has a line between 1 and 3 that
  the matrix lacks (\cref{sec:drawing}). Because the problem statement says that the graph is
  given through its adjacency matrix, the \emph{matrix} is the example. Its
  graph has the two edges $n_1n_2$ and $n_2n_3$ and is called the
  \emph{board graph}.
\item\label{conv:path} \textbf{The word ``path''.} In the course, ``path''
  means a walk with no repeated vertex (a walk is a route along edges, which
  may revisit vertices and edges, so $n_1n_2n_1$ is a walk but not a path;
  \cref{def:walk}). This is the textbook's
  Definition~1.2.13, the \emph{simple path} \cite{petrosyan2015graphs}; that
  the course uses it is part of the relayed assignment \cite{userstatements}.
  The textbook's own word ``path'' means something else, which this note
  calls a \emph{trail}; \cref{tab:naming} compares the words.
\item\label{conv:length} \textbf{Length~0.} A single vertex counts as a walk
  of length 0. This is chosen so that the identity matrix $A^0=I$ counts
  walks too: from each vertex to itself there is one walk of length 0, and
  between different vertices there is none. The textbook's definitions do
  not say this in words, but its usage assumes it
  \cite[pp.~23, 49]{petrosyan2015graphs}, and Grinberg's definition of a
  walk allows it \cite[Definition~2.9.1(a), p.~36]{grinberg2025graph}. It is
  this note's own convention.
\item\label{conv:proofs} \textbf{Who proves what.} As far as a search of its
  text showed, the textbook contains neither the walk-counting theorem nor
  a matrix test for connectivity (details in \cref{app:repro})
  \cite{petrosyan2015graphs}. This note proves both, and names in the first
  sentence after each statement the sources that also state it.
\end{enumerate}

\subsection{The story}\label{sec:story}

One story is told throughout, and every plain-words paragraph uses only
its words. A pond has some \emph{islands}. Some pairs of islands have
a \emph{bridge} between them. A frog sits on an island and makes
\emph{hops}: each hop crosses one bridge to a \emph{next-door} island. The
frog may hop back, and may use the same bridge again. A square
\emph{table} has one row and one column for each island. A cell holds a
one if the row island and the column island are next door to each other.
Otherwise it holds a zero. \Cref{tab:dictionary} gives the dictionary. Each
story word stands for one technical term. In the formal text, the
plain-words paragraph comes first and uses only story words; the
definition that follows gives the technical term.

door, table, cell, trip, fresh-island trip, and in one piece.

\subsection{The answers in brief}

\begin{itemize}
\item (Q1) The entry in row $i$ and column $j$ of $A^k$ is the number of
  walks of length $k$ from $n_i$ to $n_j$ (\cref{thm:counting}). It
  counts walks, not paths (\cref{ex:notpaths}), and it is not simply $1$
  when $n_j$ can be reached from $n_i$ (\cref{ex:notreach}).
\item (Q2) $G$ is connected if and only if every entry off the diagonal of
  $B=A+A^2+\dots+A^{N-1}$ is positive, which holds if and only if
  $(I+A)^{N-1}$ has no zero entry (\cref{thm:sum,thm:power}). A single
  power is not a test (\cref{ex:single}).
\item (Q3) A path between $n_i$ and $n_j$ is a sequence
  $n_i=u_0,u_1,\dots,u_k=n_j$ of pairwise distinct vertices in which
  consecutive vertices are adjacent (\cref{def:pathbetween}).
\end{itemize}

\subsection{Organisation and reading guide}

\Cref{sec:background} fixes the graph, the adjacency matrix, and matrix
powers. \Cref{sec:walks} introduces walks, trails, paths, and cycles in the
textbook's order and answers (Q3). \Cref{sec:counting} answers (Q1) and
\cref{sec:connectivity} answers (Q2), with worked examples, one connected
and one not. \Cref{sec:discussion} collects limits and the comparison with
other sources, and \cref{sec:conclusion} states the answers. The appendix
lists the sources, the pages checked, and how to rerun the scripts.

A reader who wants only the answers can read, in \cref{sec:background}, the
definitions of the adjacency matrix and of matrix powers; in
\cref{sec:walks}, the definitions of walk and path (\cref{def:walk,def:path,def:pathbetween})
and the lemma that every walk contains a path (\cref{lem:cut}) with the
bound on the length of a path (\cref{cor:bound}); in \cref{sec:counting},
the walk-counting theorem (\cref{thm:counting}); and in
\cref{sec:connectivity}, the definition of connected, the reachability
lemma (\cref{lem:reach}), the sum test (\cref{thm:sum}), and the examples. Trails, cycles, distance, components, the power
test, and \cref{sec:discussion} are not needed for (Q1) to (Q3).
