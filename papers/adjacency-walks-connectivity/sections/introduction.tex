\section{Introduction}\label{sec:introduction}

A graph is a set of points, called vertices, together with lines, called edges, that join some pairs of points. A computer often stores a graph as a table of zeros and ones, the adjacency matrix $A$, which has a $1$ in row $i$ and column $j$ when vertices $n_i$ and $n_j$ are joined by an edge. This note asks what can be read from that table alone. It has three questions.

\begin{enumerate}
\item[(Q1)] What does the entry $(A^k)_{ij}$ of the $k$-th power of $A$ represent?
\item[(Q2)] How can one decide, using only $A$, whether the graph is connected?
\item[(Q3)] What is the definition of a path between the vertices $n_i$ and $n_j$?
\end{enumerate}

\paragraph{Where the questions come from.} Questions (Q1) and (Q2) are reconstructed from a lecture whiteboard, photographed twice from slightly different angles \cite{whiteboard1,whiteboard2}. The board reads, in the handwriting's own words, ``What does $A_{ij}$ represent'' for question 1, with a small mark above the letter $A$, and ``How to know if graph is connected or not'' for question 2. The same board gives the definition ``Graph is called connected if for any $n_i, n_j$ there exists a path between nodes'' \cite{whiteboard1}. The small mark is read as an exponent $k$, so that question 1 becomes (Q1), because the assignment asks about $A^k$ (Convention~3 below); this reading is an interpretation. Question (Q3) is not on the board. It comes from the assignment text, as reported to the author of this note; that text is not reproduced here, so (Q3) is best taken as the third question this note has chosen to answer.

\paragraph{Why it matters.} A table of zeros and ones looks like it holds only direct connections. Question (Q1) shows that multiplying the table by itself answers a richer question, namely how many ways there are to travel between two vertices in a fixed number of moves. Question (Q2) turns that into a yes or no answer about the whole graph, and question (Q3) fixes the word ``path'' on which the board's definition of connected rests.

\paragraph{Short answers.} Each is stated with its proof later.
\begin{enumerate}
\item[(A1)] For every integer $k \ge 1$, the entry $(A^k)_{ij}$ counts the walks of length exactly $k$ from $n_i$ to $n_j$ (\Cref{thm:walkcount}). It counts walks, not paths (\Cref{prop:notpaths}).
\item[(A2)] A graph with $N$ vertices is connected if and only if every entry of $A + A^2 + \dots + A^{N-1}$ that is not on the diagonal is positive (\Cref{thm:sumtest}). Equivalently, $(I+A)^{N-1}$ has no zero entry (\Cref{thm:powertest}), where $I$ is the identity matrix.
\item[(A3)] In the convention of the course, a path between $n_i$ and $n_j$ is a sequence of vertices that starts at $n_i$, ends at $n_j$, has an edge between each two neighbours in the sequence, and never repeats a vertex (\Cref{def:path}).
\end{enumerate}

\paragraph{Conventions and assumptions.} The following items fix the readings and choices of this note. Later text refers to them by number.
\begin{enumerate}
\item \emph{Graphs.} Every graph is finite, simple, and undirected. Simple means no edge joins a vertex to itself and no two edges join the same pair. The assignment text states this, and it fits the board matrix, which is symmetric with zeros on its diagonal.
\item \emph{Notation.} The board writes the graph as $(G,V)$ and an edge as $e_{ij} \in V$. The course textbook writes $G = (V,E)$ with $E$ the set of edges \cite[Def.~1.1.1, p.~9]{petrosyan2015grafneri}. This is a difference of notation only, and this note uses the textbook's $G=(V,E)$. Vertices are named $n_1, \dots, n_N$ as on the board, where $N$ is the number of vertices; the textbook names them $v_i$ \cite[p.~11]{petrosyan2015grafneri}.
\item \emph{The mark above $A$.} The mark is read as an exponent $k$. This is an interpretation: the photographs show only a small mark, and the assignment text asks about $A^k$. If the mark is instead a quotation mark, question 1 asks what $A_{ij}$ represents; that is answered by \Cref{def:adjmatrix} and by the case $k=1$ of \Cref{thm:walkcount}.
\item \emph{The example graph.} The board shows a drawing and a $3\times 3$ matrix that do not describe the same graph, as \Cref{tab:mismatch} in \Cref{sec:examples} sets out edge by edge. The matrix is taken as the example, because the problem statement on the board says that the graph is given through its adjacency matrix. The drawing as read is shown in \Cref{fig:boarddrawing}. The arrowhead on the line from $1$ to $2$ is read as a stray mark, because the matrix is symmetric and the problem concerns undirected graphs. The note does not claim to know what the lecturer intended.
\item \emph{The word ``path''.} In the course, a path has no repeated vertex. This is the textbook's simple path, Definition~1.2.13 \cite[p.~22]{petrosyan2015grafneri}. The textbook's own word ``path'' (Definition~1.2.12) means a walk with no repeated edge; this note calls that a \emph{trail}, with the textbook's number beside it where the textbook's wording is meant. In short: the textbook's ``path'' is this note's trail, and the textbook's ``simple path'' is this note's path. \Cref{tab:naming} compares the conventions.
\item \emph{Length zero.} A single vertex counts as a walk of length $0$. This is the note's own convention. The textbook's Definitions 1.2.10 to 1.2.16 do not say whether length $0$ is allowed \cite{petrosyan2015grafneri}. Two of its statements assume a trail of length $0$ from a vertex to itself, namely that $d(u,v)=0$ if and only if $u=v$ (p.~23) and that its relation $\sim$ is reflexive (p.~49) \cite[pp.~23, 49]{petrosyan2015grafneri}, so this convention agrees with the textbook's usage. Grinberg also allows length $0$ \cite[Def.~2.9.1(a), p.~36]{grinberg2025graph}. A cycle always has positive length. Without this convention, ``any two vertices'' in the definition of connected would have to be read as two different vertices (\Cref{rem:readingconnected}).
\item \emph{Page numbers.} Pages of the textbook are printed page numbers, which are the PDF page numbers minus one. The textbook is in Armenian; the definition numbers are the book's own. Its term for the adjacency matrix is, in transliteration, \emph{harevanutyan matrits}; the Armenian script is not typeset in this note. A reader who cannot read Armenian cannot check the textbook citations directly, so every definition taken from the book is restated in English here and its number and page are given.
\item \emph{Kinds of statement.} A definition carries the number of the source it comes from. A lemma or theorem followed by a proof is proved here; the sources that also state it are cited in its first sentence. The textbook contains no walk-counting theorem and no matrix test for connectivity. A text search of its 216 pages for the term for adjacency matrix finds the term only on printed pages 7, 11, 12, 34, and 61, and the text layer of these pages contains neither result \cite{petrosyan2015grafneri}. This is the result of a search, not a proof of absence, so both results are taken from other sources and proved here.
\end{enumerate}
